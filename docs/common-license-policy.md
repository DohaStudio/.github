# 공통 라이선스 정책

> 문서 상태: [제안]

다음 권리와 라이선스는 독립적으로 검토합니다.

1. Repository code와 documentation
2. Dataset과 AIHub package
3. 외부 모델 code
4. 모델 weight, Adapter와 Checkpoint
5. Generated Content와 Workspace export
6. 개인 음성, Recording과 Consent

코드 라이선스가 허용적이어도 Dataset 학습, weight 재배포나 생성 결과의 상업 이용이 자동 승인되지 않습니다. Model/Dataset Manifest에 검토 상태와 근거를 연결하고 불확실하면 `REVIEW_REQUIRED` 또는 `[검증 필요]`로 유지합니다.

`.github` 저장소의 코드·문서는 [Apache License 2.0](../LICENSE)을 적용합니다. 이 라이선스는 Dataset, 외부 모델, 모델 가중치, Checkpoint, Adapter, 생성 결과, 개인 음성, 동의 증적과 제3자 콘텐츠에 적용되지 않습니다. 각 항목은 출처·권리·상업 이용·재배포 조건을 별도로 검토해야 합니다.
